Consulta de pedidos

Acompanhe os pedidos com cliente, itens, funcionário responsável e valores. Liste os pedidos em aberto, abra um pedido pelo ID e atualize o status conforme o fluxo da empresa.

— pedidos encontrados — abertos — em processamento — concluídos — cancelados
Detalhes Pedido ID cliente Cliente Data do atendimento Valor total Status Alterar status
Clique em “Pedidos em aberto” ou “Listar todos” para carregar os registros.

API: GET /api/pedidos lista (aceita ?status=Aberto); GET /api/pedidos/:id consulta por ID; PATCH /api/pedidos/:id/status altera o status. Se o ID não existir, a API responde com HTTP 404; transições inválidas são recusadas pelo backend (HTTP 409/422).

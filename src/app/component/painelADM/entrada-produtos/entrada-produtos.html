Registrar entrada de produtos

Registre os produtos recebidos pelo estoque. Ao confirmar, a movimentação será enviada ao backend, que grava a entrada e deixa o trigger do banco atualizar a quantidade e os valores do produto.

O que acontece ao confirmar?

Atualização feita no banco de dadosO Angular não altera o estoque diretamente. Ele apenas envia os dados ao backend.
1
Registrar a movimentação
O backend insere a entrada em entrada_produto.
2
Executar o trigger
O trigger existente atualiza a quantidade em estoque e o valor do produto. Não é necessário repetir essa lógica no frontend.
3
Concluir tudo junto
O insert e a atualização do trigger participam da mesma transação. Se ocorrer um erro, o backend deve fazer rollback.
Integração necessáriaEste HTML espera uma API em /api/entradas-produto e uma API de produtos em /api/produtos. Ajuste os endereços conforme seu backend.
